프로젝트 루트의 `.production/workflow.md`에서 현재 단계의 `## NN.` 구간과 필요한 Flow 도움말만 읽는다. work/status.md의 진행 기록의 승인 시나리오 버전·모드와 장면 목록을 대조한다. 7단계 최신 장면·전환 판정이 빠졌거나 입력 버전이 달라졌으면 콘티 담당으로 돌아간다. 순차 모드에서는 단계마다 사용자 확인을 받는다. 승인 시나리오에 없는 인물·대사·내레이션·음악·효과음·엔딩은 해당 없음으로 기록하고 추가하지 않는다. 무성 조건은 트랙·출력 기준에 명시한다.

생성한 이미지·영상은 .production/layout.md를 따라 저장하고 실제 경로와 버전을 work/status.md에 남긴다.

1. 8단계는 해당 장면·인접 연결의 콘티와 참조, 대사 원문, 연출·음향 조건만 본다. 시작·끝 상태, 무언 표정·행동, 화면 밖 내레이션의 감정·발음·속도, 사용자가 허용한 음향과 다음 컷까지 이어질 소리를 명시한다. 소재 모드에서는 한·영 프롬프트에 @파일명과 그 소재의 역할을 함께 적는다. Flow 제출 시 입력란에서 @를 입력하고 목록에서 해당 프로젝트 소재를 선택한다. 생성 직전에 본문 안의 소재 태그 이름·개수·역할을 제출본과 대조한다. 채택 콘티가 있는 각 컷은 콘티 파일명을 첨부 목록, 한·영 본문의 @태그, 실제 Flow 본문의 연결 태그와 차례로 대조한다. 시작·끝 이미지 지정이 없으면 콘티도 소재로 연결한다. 지정 소재를 모두 연결할 수 없는 경우에는 누락한 상태로 전송하지 않고 해당 컷의 구성을 확인한다. 카메라는 고정을 기본으로 한다. 시나리오에 꼭 필요한 동작은 시작 위치를 가까이 잡아 이동 거리와 회전 폭을 줄이고, 여러 동작은 차례로 마친다. 최신 승인 연출이 요구하는 움직임만 두 언어판에 남긴다. 승인된 내레이션은 기본적으로 장면 영상과 함께 생성한다. 화면 동작, 화면 밖 화자의 목소리·연기, 승인 대사 원문을 Flow에 한 번에 제출하는 같은 프롬프트에 쓴다. 사용자가 별도 녹음이나 제공 음원을 지정한 경우에만 해당 방식을 기록해 적용한다. 음성 참조는 특정 음색을 재현할 때 쓰는 선택 입력이다. 음성 참조를 첨부할 수 없어도 동시 발화를 지원하면 같은 화자 설명으로 진행한다. 선택한 모델·모드의 동시 발화 지원이 불확실하면 그 기능을 확인하고, 미지원이면 동시 생성이 가능한 설정을 먼저 검토한다. 제작 방식을 변경해야 할 때만 사용자에게 확인한다. 같은 버전의 한국어 검토본과 영어 제출본을 전문으로 작성한다. Flow에는 영어 제출본을 넣고 실제 발화는 승인된 언어의 대사 원문을 그대로 둔다. 시나리오의 각 감정을 영어 제출본 안에서 호흡·쉼·강세로 구체화하고 같은 화자의 음색을 유지한다. 현재 프로젝트에서 지정한 모델명·버전을 제출 화면과 대조한다. 시작 이미지와 끝 이미지가 모두 미지정이면 Flow의 소재(Ingredients) 모드를 사용한다. 사용자 또는 승인 시나리오가 특정 이미지를 시작이나 끝으로 지정한 컷만 프레임(Frames) 모드로 만들고, 지정된 파일만 해당 위치에 넣는다. 이미지 용도 기록과 실제 선택한 슬롯을 9단계 검수와 10단계 제출 직전에 대조한다. 작품별 모델명과 발화 조건을 따른다. 지원 여부를 확인하지 못하면 계획을 초안으로 남기고 8단계에서 대기한다. 화면 접근이 가능해지면 모델·참조 모드·첨부 가능 여부를 확인한다.
2. 프롬프트를 읽기 전에 마지막으로 승인된 시나리오의 버전과 해당 구간을 표시하고, 그 구간에서 반드시 보여야 할 행동·감정 변화, 들려야 할 대사, 전환·엔딩 조건을 관찰 가능한 통과 기준으로 적는다. 이후 승인된 콘티나 사용자 변경 사항은 출처를 구분한다. 한국어판과 영어판 각각을 같은 기준으로 판정하고 근거를 남긴다. 시나리오 요구가 빠졌거나 양쪽 의미가 다르면 해당 장면을 수정하고 재검수한다. 생성 후 사용자가 확인할 항목은 별도로 표시한다. 동시 생성 장면은 Flow에 실제로 보낼 입력만 따로 읽고, 화면 밖 화자와 승인 대사 원문이 모두 들어 있는지 확인한다. 대사가 제출문 밖 메모에만 있거나 전체 무음 지시와 충돌하면 8단계에서 고친다. 전부 통과한 뒤 10단계에서는 이번에 요청받은 컷의 영어 제출문만 전송한다. 프롬프트 작성 요청은 해당 문서 저장으로 마친다. 재개 시 기존 요청 ID와 결과를 조회해 중복 생성을 피한다.
3. 11단계는 생성본 사용자 확인 지점이다. 요청받은 컷의 저장과 재생 가능 여부를 확인하고 장면 번호·버전·링크를 전달한다. 연기·립싱크·동작·발음·음색은 사용자가 직접 판단한다. 사용자 의견이 오면 통과·수정·제외로 기록한다. 사용자가 이미 파일을 선택해 편집을 요청했다면 그 선택과 생성 ID를 편집 담당에게 넘긴다. 선택이 필요한 경우에만 확인 대기로 둔다.
4. 사용자가 선택한 컷의 영상·음성 출처, 사용 구간, 승인 대사, 엔딩과 편집 지시를 hyperframes-preview-edit에 넘긴다. 수정·재생성은 사용자가 지정한 범위에 적용한다.

이 작품처럼 사용자가 표정 연기만 지정한 컷은 콘티의 자세·카메라·인물 위치와 소품 배치를 유지한다. 감정은 눈빛·눈썹의 작은 변화로 지정한다. 입술은 붙어 있고 턱은 정지한다. 내레이션의 질문·강세·쉼이나 책 제목을 화면 인물의 대사 또는 입 모양으로 옮기지 않는다. 이전 시나리오에 걷기·착석·담요 펼치기가 있어도 최신 사용자 수정이 해당 동작을 제외하면 한·영 제출문 양쪽에서 삭제한다. 장면마다 첫 자세, 허용되는 변화, 끝까지 고정할 대상을 구체적으로 쓴다.
