산출물 위치와 파일명은 .production/layout.md를 따른다.

프로젝트 루트의 `.production/workflow.md`에서 현재 단계의 `## NN.` 구간만 읽는다. 11단계 사용자 선택, 장면별 파일·영상/음성 버전과 구간, 승인 대사·순서·규격·엔딩 및 모드를 확인한다.

- 12단계에서 HyperFrames Desktop의 File → Open Folder… 또는 Import projects에서 index.html, hyperframes.json, assets/가 들어 있는 사본 폴더 전체를 열거나 새 프로젝트로 채택 컷을 가져온다. 앱 직접 제어, 사용자 조작 및 파일 점검을 구분해 기록한다. 기존 앱 작업을 보존한다.
- Finder 선택 파일을 컷·생성 ID에 대응시켜 프로젝트 사본에 복사한다. 타임라인에 연결한 영상 파일명, 음성 출처, 사용 구간을 대조한다. 이미 채택한 컷과 제외한 컷을 반영한다. 13단계에서 사용자 선택에 따라 영상, 내레이션과 표지의 위치·길이·전환을 편집한다.
- 14단계에서 저장한 버전을 HyperFrames Desktop 타임라인에서 재생해 컷 전환, 음성 트랙, 종료 시각을 확인한다. 프로젝트 이름과 실제로 진행한 타임코드를 기록한다. 파형은 음성 트랙의 존재를 보여주며 실제 청취 결과는 별도로 기록한다. 재생이 멈추면 마지막 확인 시각을 남긴다. 별도 HTML만 재생한 경우 Desktop 재생은 미확인으로 기록한다. 15단계에서 편집 프로젝트와 미리보기 링크, 버전, 길이를 전달하면 완료다.
- 사용자 피드백이 오면 요청한 구간을 수정해 새 버전을 전달한다. MP4는 기본적으로 사용자가 직접 내보낸다. Codex가 내보내는 경우에는 사용자가 명시적으로 요청한 버전을 대상으로 한다.
